# Halagannada Keyboard (No Mahapranas) | ಹಳಗನ್ನಡ ಕೀಬೋರ್ಡ್ (ಮಹಾಪ್ರಾಣ ಮುಕ್ತ)

## English

A custom keyboard layout designed specifically for **hobbyists and enthusiasts of Halagannada (Old Kannada)**. 

To simplify typing and digital expression of Old Kannada, this keyboard intentionally **excludes Mahapranas** (aspirated consonants like ಖ, ಘ, ಛ, ಝ, etc.), focusing purely on the core phonetic structure used in classic poetry, inscriptions, and literature.

### ✨ Features
* **Halagannada Focused:** Tailored for typing vocabulary from classic Old Kannada literature.
* **No Mahapranas:** Optimized for a streamlined layout by removing heavy aspirated sounds not strictly required for basic Halagannada hobby projects.
* **Hobbyist Friendly:** Easy to install, learn, and use for casual writing, poetry, and historical exploration.

### 📥 Installation //To-Do
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Follow the OS-specific setup instructions in the `/docs` folder.
3. Switch your system keyboard input to **Halagannada (No Mahaprana)**.

## ಕನ್ನಡ (Kannada)

**ಹಳಗನ್ನಡ ಹವ್ಯಾಸಿಗಳು ಮತ್ತು ಉತ್ಸಾಹಿಗಳಿಗಾಗಿ** ಪ್ರತ್ಯೇಕವಾಗಿ ವಿನ್ಯಾಸಗೊಳಿಸಲಾದ ಕಸ್ಟಮ್ ಕೀಬೋರ್ಡ್ ಲೇಔಟ್.

ಹಳಗನ್ನಡವನ್ನು ಡಿಜಿಟಲ್ ರೂಪದಲ್ಲಿ ಸುಲಭವಾಗಿ ಟೈಪ್ ಮಾಡಲು, ಈ ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ **ಮಹಾಪ್ರಾಣ ಅಕ್ಷರಗಳನ್ನು** (ಖ, ಘ, ಛ, ಝ ಮುಂತಾದವುಗಳನ್ನು) ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ **ತೆಗೆದುಹಾಕಲಾಗಿದೆ**. ಹಳೆಯ ಕಾವ್ಯಗಳು, ಶಾಸನಗಳು ಮತ್ತು ಸಾಹಿತ್ಯದಲ್ಲಿ ಬಳಸಲಾಗುವ ಪ್ರಮುಖ ಧ್ವನಿ ರಚನೆಯ ಮೇಲೆ ಮಾತ್ರ ಇದು ಗಮನ ಹರಿಸುತ್ತದೆ.

### ✨ ವೈಶಿಷ್ಟ್ಯಗಳು
* **ಹಳಗನ್ನಡ ಕೇಂದ್ರಿತ:** ಕ್ಲಾಸಿಕ್ ಹಳಗನ್ನಡ ಸಾಹಿತ್ಯದ ಪದಗಳನ್ನು ಟೈಪ್ ಮಾಡಲು ಸೂಕ್ತವಾಗಿದೆ.
* **ಮಹಾಪ್ರಾಣ ಮುಕ್ತ:** ಹವ್ಯಾಸಿ ಯೋಜನೆಗಳಿಗೆ ಕಡ್ಡಾಯವಾಗಿ ಇಲ್ಲದ ಮಹಾಪ್ರಾಣ ಧ್ವನಿಗಳನ್ನು ತೆಗೆದುಹಾಕುವ ಮೂಲಕ ಲೇಔಟ್ ಅನ್ನು ಸರಳಗೊಳಿಸಲಾಗಿದೆ.
* **ಹವ್ಯಾಸಿ ಸ್ನೇಹಿ:** ಸಾಹಿತ್ಯಾಸಕ್ತರು, ಕವಿಗಳು ಮತ್ತು ಇತಿಹಾಸ ಪ್ರೇಮಿಗಳು ಸುಲಭವಾಗಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಲು ಮತ್ತು ಬಳಸಲು ಅನುಕೂಲಕರವಾಗಿದೆ.
